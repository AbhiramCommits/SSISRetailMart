# RetailMart data dictionary

## Staging (`stg`, untyped landing)

Source columns stay `VARCHAR` on purpose; the SSIS pipeline writes a small set of
typed/derived columns alongside the raw string.

### `stg.stores_raw`
Grain: one row per `stores.txt` record per batch.

| Column | Type | Notes / lineage |
| --- | --- | --- |
| `store_raw_id` | BIGINT IDENTITY | surrogate |
| `batch_id` | BIGINT | ETL batch |
| `source_file` | NVARCHAR(260) | `stores.txt` |
| `row_num` | INT | line number |
| `store_code` | VARCHAR(50) | fixed-width cols 1–6 |
| `store_name` | VARCHAR(200) | cols 7–46 |
| `region` | VARCHAR(100) | cols 47–58 |
| `country` | VARCHAR(50) | cols 59–61 |
| `open_date_raw` | VARCHAR(50) | cols 62–71 |
| `clean_store_code` | VARCHAR(50) | `TRIM(UPPER(store_code))` |
| `clean_store_name` | VARCHAR(200) | `TRIM(UPPER(store_name))` |
| `clean_region` | VARCHAR(100) | `TRIM(region)` |
| `open_date` | DATE | safe `(DT_DATE)` parse |
| `is_valid` | BIT | passed the conditional split |
| `load_ts` | DATETIME2(3) | default `SYSUTCDATETIME()` |

### `stg.sales_raw`
Grain: one row per `sales_YYYYMMDD.csv` line per batch.

| Column | Type | Notes / lineage |
| --- | --- | --- |
| `sales_raw_id` | BIGINT IDENTITY | surrogate |
| `batch_id` | BIGINT | ETL batch |
| `source_file` | NVARCHAR(260) | `sales_YYYYMMDD.csv` |
| `row_num` | INT | line number |
| `txn_id` | VARCHAR(50) | source |
| `txn_ts_raw` | VARCHAR(50) | source timestamp text |
| `store_code` | VARCHAR(50) | source |
| `sku` | VARCHAR(50) | source |
| `qty_raw` / `unit_price_raw` / `discount_pct_raw` | VARCHAR(50) | source text |
| `channel` | VARCHAR(50) | `Store`/`Online`/`App` |
| `qty` | INT | `(DT_I4)[qty]` |
| `unit_price` | DECIMAL(18,4) | `(DT_DECIMAL,4)` |
| `discount_pct` | DECIMAL(9,4) | `(DT_DECIMAL,4)` |
| `date_key` | INT | `YEAR*10000+MONTH*100+DAY` of `txn_ts` |
| `gross_amount` | DECIMAL(18,4) | `qty * unit_price` |
| `discount_amount` | DECIMAL(18,4) | `gross * discount_pct / 100` |
| `net_amount` | DECIMAL(18,4) | `gross − discount` |
| `is_valid` | BIT | passed the conditional split |
| `load_ts` | DATETIME2(3) | default |

### `stg.products_raw`
Grain: one row per product snapshot or change per batch.

| Column | Type | Notes / lineage |
| --- | --- | --- |
| `product_raw_id` | BIGINT IDENTITY | surrogate |
| `batch_id` | BIGINT | ETL batch |
| `source_file` | NVARCHAR(260) | page/change JSON file |
| `row_num` | INT | item index |
| `sku` | VARCHAR(50) | JSON `sku` |
| `name` / `category` / `subcategory` / `brand` | VARCHAR(100–200) | JSON |
| `list_price` | VARCHAR(50) | JSON price as text |
| `is_active` | VARCHAR(10) | JSON boolean as text |
| `effective_date` | DATE | change date (base rows = window start) |
| `row_hash` | CHAR(64) | SHA-256 over managed attributes |
| `load_ts` | DATETIME2(3) | default |

## Dimensions (`dw`)

### `dw.dim_date`
Grain: one row per calendar day, 2019-01-01 … 2027-12-31. Source: generated by
`dw.sp_populate_dim_date`.

| Column | Type | Notes |
| --- | --- | --- |
| `date_key` | INT (PK) | `YYYYMMDD` |
| `full_date` | DATE | calendar date (date-table column) |
| `year` / `quarter` / `month` | INT | calendar parts |
| `month_name` | VARCHAR(20) | `DATENAME(MONTH)` |
| `day_of_month` | INT | day |
| `day_of_week` | INT | `DATEPART(WEEKDAY)` |
| `day_name` | VARCHAR(20) | `DATENAME(WEEKDAY)` |
| `week_of_year` | INT | `DATEPART(ISO_WEEK)` |
| `fiscal_year` | INT | = calendar year |
| `fiscal_period` | INT | = calendar month |
| `is_weekend` | BIT | Sat/Sun |
| `is_holiday_us` | BIT | fixed-date US holidays |

### `dw.dim_store` (SCD Type 1)
Grain: one row per `store_code`. Loaded by `dw.sp_load_dim_store` (MERGE,
attributes overwritten).

| Column | Type | Notes / lineage |
| --- | --- | --- |
| `store_sk` | INT IDENTITY (PK, NC) | surrogate; `-1` = unknown |
| `store_code` | VARCHAR(50) (UQ) | business key, from `stg.stores_raw.clean_store_code` |
| `store_name` | VARCHAR(200) | cleaned name |
| `region` | VARCHAR(100) | cleaned region |
| `country` | VARCHAR(50) | cleaned country |
| `open_date` | DATE | parsed store open date |
| `is_unknown` | BIT | 1 for the `-1` member |
| `created_at` / `updated_at` | DATETIME2(3) | audit timestamps |

### `dw.dim_product` (SCD Type 2)
Grain: one row per product **version**. Loaded by
`dw.sp_load_dim_product_scd2` (expire-and-insert on `row_hash`, ordered by
`effective_date`).

| Column | Type | Notes / lineage |
| --- | --- | --- |
| `product_sk` | INT IDENTITY (PK, NC) | surrogate; `-1` = unknown |
| `sku` | VARCHAR(50) | business key, from `stg.products_raw` |
| `name` / `category` / `subcategory` / `brand` | VARCHAR | managed attributes |
| `list_price` | DECIMAL(18,4) | managed attribute |
| `is_active` | BIT | managed attribute |
| `valid_from` | DATE | `effective_date` of the change |
| `valid_to` | DATE | day before the next `effective_date`; NULL = current |
| `is_current` | BIT | exactly one per SKU |
| `row_hash` | CHAR(64) | SHA-256 over the managed attributes |
| `inserted_at` | DATETIME2(3) | version insert time |

## Facts (`dw`)

### `dw.fact_sales`
Grain: one row per sales transaction line. Loaded by
`dw.sp_load_fact_sales_incremental` (batch-only, unknown-member substitution, SCD
version valid on the sale date, idempotent on `txn_id`).

| Column | Type | Notes / lineage |
| --- | --- | --- |
| `sale_sk` | BIGINT IDENTITY (PK, NC) | surrogate |
| `date_key` | INT | FK `dim_date`; from `stg.sales_raw.date_key` |
| `product_sk` | INT | FK `dim_product`; version valid on the sale date, else `-1` |
| `store_sk` | INT | FK `dim_store`; else `-1` |
| `txn_id` | VARCHAR(50) (UQ) | idempotency key |
| `qty` | INT | units |
| `unit_price` | DECIMAL(18,4) | price |
| `discount_pct` | DECIMAL(9,4) | discount |
| `gross_amount` | DECIMAL(18,4) | `qty × unit_price` |
| `discount_amount` | DECIMAL(18,4) | discount value |
| `net_amount` | DECIMAL(18,4) | `gross − discount` |
| `channel` | VARCHAR(20) | source channel |
| `batch_id` | BIGINT | originating ETL batch |
| `load_ts` | DATETIME2(3) | default |

Indexes: clustered `(date_key, store_sk)`; nonclustered `(product_sk)`;
unique nonclustered `(txn_id)`.

### `dw.fact_inventory_snapshot`
Grain: one row per (business date, product version, store). Loaded by
`dw.sp_build_inventory_snapshot` (safety stock 9–13 minus units sold).

| Column | Type | Notes |
| --- | --- | --- |
| `snapshot_sk` | BIGINT IDENTITY (PK, NC) | surrogate |
| `date_key` | INT | FK `dim_date` |
| `product_sk` | INT | FK `dim_product` |
| `store_sk` | INT | FK `dim_store` |
| `on_hand_qty` | INT | max(0, base stock − units sold) |
| `is_stockout` | BIT | 1 when on-hand ≤ 0 |
| `batch_id` | BIGINT | originating batch |
| `load_ts` | DATETIME2(3) | default |

## Reporting views (`dw`)

| View | Grain | Source |
| --- | --- | --- |
| `dw.vw_sales_trend` | one row per date (sales KPIs) | `fact_sales` ⋈ `dim_date` |
| `dw.vw_stockouts` | one row per inventory snapshot with dimensions | `fact_inventory_snapshot` ⋈ `dim_date`/`dim_product`/`dim_store` |
| `dw.vw_load_health` | one row per (batch, package) | `audit.etl_batch` |
| `dw.vw_load_health_summary` | one row per batch | `audit.etl_batch` aggregate |

## Audit (`audit`) and data quality (`dq`)

| Table | Grain | Key columns |
| --- | --- | --- |
| `audit.etl_batch` | per (batch, package) | status, rows_read/inserted/updated/rejected, duration_ms |
| `audit.row_count_check` | per (batch, table) | source_rows, target_rows, delta |
| `audit.checksum_check` | per (batch, table, column) | source_checksum, target_checksum, matched |
| `audit.failed_rows` | per rejected record | component, error_code, error_column, raw_row, error_description |
| `dq.assertion_result` | per (batch, assertion) | status, observed_value, threshold |
